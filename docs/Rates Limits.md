#  Rates Limits
 
!!! Note

     In order to make sure all clients requests are treated equally,  jainam has setup certain limits to the number of requests each client can make through API.

## Introduction

The following are the rate limits for API users

1. Orders -<u> **NOT LIMITED**</u>. Placing a new order, Modifying an existing order, square off positions and Cancelling an order are all not limited.


2. All other requests --<u> **Limited to 1800 requests per 15 minitues**</u>. This limit will be reset every 15 minutes to 1800 again.
